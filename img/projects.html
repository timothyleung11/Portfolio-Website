Projects

Things I've designed and built — mostly nerf blasters and small simulations, mostly born from wanting to know exactly how something works.

Class: Pneumatic Systems

Air-powered Nerf Blaster

field note —

Inspired by JSPB blasters, I designed an air-powered blaster using PVC pipes, check valves, and various custom adaptors to make it work.

Class: Kinetic Systems

Flywheel Nerf Blaster

field note —

I designed 3D-printed parts to mount two toy motors, then tested current draw, RPM, torque, and dart velocity across a range of voltages.

Class: Computational Models

CLI Projectile Simulator

field note —

I programmed a projectile-motion simulation in Java that lets a user define a projectile's properties and see how far it would travel under different launch conditions.
